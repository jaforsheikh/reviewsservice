# 📦 Installation

## 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/reviewsservice.git
```

---

## 2. Navigate to Theme

```bash
cd reviewsservice
```

---

## 3. Install Dependencies

```bash
npm install
```

---

## 4. Start Tailwind Watch

```bash
npm run dev
```

---

## 5. Production Build

```bash
npm run build
```

---

# 🛠 Development Workflow

## Start Development

```bash
npm run dev
```

## Build Production CSS
